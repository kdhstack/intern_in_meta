# 프로젝트 개요
> 이 프로젝트는 전자상거래 업체인 '슈킹'의 온라인 쇼핑몰을 구현합니다.
> 온라인 쇼핑몰을 통해 슈킹의 구매율을 높이고 상품 구매까지의 과정이 편리해지게 만드는 것이 목표입니다.
> 해당 웹페이지는 사용자가 상품을 자유롭게 구경하고 선택할 수 있게 하며, 장바구니에 담는 것과 카드를 이용하여 결제할 수 있게 합니다.
> 각 기능은 function으로 구분되어있으며, MainApp 함수에서 하나로 통합되어 구현되고, App 함수에서 Router를 적용하여 구동됩니다.

# 시스템 아키텍처
> 시스템의 전체적인 구조와 각 컴포넌트가 어떻게 연동되는지를 도식화하여 설명합니다. 이전 문서에서 작성했던 내용이 있다면 링크를 정리해하셔도 좋습니다.

# 개발 환경 설정 및 규칙
> 개발을 시작하기 위해 필요한 환경 설정에 대한 자세한 단계를 포함합니다. 프로젝트 주차가 진행되면서 조금씩 추가되거나 변경된 요소를 한 번에 정리합니다. 또한 코드 저장소의 구조, 사용되는 브랜치 전략, 커밋 메시지 규칙 등을 설명합니다.

> React 18.3.1, 
> react-router-dom 7.9.6, 
> Recoil 0.7.7 버전을 사용합니다.

> 메인 화면은 https://kdhstack.github.io/intern_in_meta(로컬에서는 localhost:3000/intern_in_meta)입니다.
> 서버는 db.json을 이용해 mock server를 만들어 운영하며, 이 때문에 터미널 창을 두 개 열어서 하나는 서버를, 하나는 웹페이지를 구동해야합니다.

> `npm start`: 웹페이지 구동
> `npm run start:server`: mock server 구동

> 커밋 메시지는 링크(https://velog.io/@shin6403/Git-git-%EC%BB%A4%EB%B0%8B-%EC%BB%A8%EB%B2%A4%EC%85%98-%EC%84%A4%EC%A0%95%ED%95%98%EA%B8%B0)를 참고했지만, 다른 요소가 있습니다.
> 새로운 기능 추가는 [Add], 버그 수정은 [Fix]를 사용하여 표기하였습니다.
