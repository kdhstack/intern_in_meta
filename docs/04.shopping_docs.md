# 쇼핑몰 연동

## 프로젝트 개요
- 프로젝트 목표: 쇼핑몰을 위해 개발한 각 기능을 통합하고, 서로 연계되어 기능할 수 있도록 구현
- 프로젝트 기능
- URL: https://github.io/kdhstack/intern_in_meta
- 참여한 팀원: 김동훈

## 개발 환경

사용한 프레임워크, 라이브러리, 언어
`React 18.3.1`, 
`react-router-dom 7.9.6`,
`recoil 0.7.7`

## 설치 및 실행 방법

프로젝트를 로컬에서 실행하기 위한 설치 방법과 명령어

프로젝트 설치
- `npm install`
- `npm install react-router-dom`
  
프로젝트 실행
- `npm start`
- `npm run start:server`

* 두 개를 각각 다른 터미널 창에서 실행시켜야합니다.

## 주요 함수와 기능
- `CheckoutPage` - 담은 상품을 최종 결제할 수 있게 구현한 페이지
  - 카드 등록과 결제 파트 연결
- `MainApp` - 기존의 App()의 역할을 수행, Route를 이용하기 위해 새로 만든 함수
- `App` - Route로 감싸진 MainApp()으로 구성

## 테스트 방법
테스트 케이스 및 실행 방법

`npm test` - 서버 구동 여부를 확인합니다.

`npx cypress open` - Cypress GUI 시스템을 이용하여 테스트 진행 - 상품이 목록에 있는 지 확인하여 서버의 활성화 여부를 확인하고 상품을 장바구니에 담는 것을 확인합니다. 

## 유의사항 및 알려진 이슈
CSS 방면에서 개선점이 있습니다.

결제 수단 선택 화면에서 장바구니 페이지를 거치지 않고 곧바로 메인 페이지로 넘어가는 기능을 추가할 수 있습니다.
