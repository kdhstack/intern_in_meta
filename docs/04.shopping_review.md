# 쇼핑몰 연동 리뷰

## 고객사 요구사항
> - 장바구니 페이지에서 상품 결제하기 버튼 클릭 시 결제 완료 페이지로 이동, 이후 다시 상품 페이지로 돌아갈 수 있도록 구현
> - 상품 목록 페이지에서 상품 클릭 시 상품 상세페이지로 이동, 관련 상품도 볼 수 있게 표시
> - 상품을 장바구니에 담지 않고 바로 구매 버튼을 클릭할 시 해당 상품을 장바구니에 1개 추가로 담고 결제 페이지로 이동

## 요구사항에 따른 기능 동작 확인
> - 결제 버튼 클릭 시 결제 완료 페이지로 이동 ✅
> - 상품 목록에서 상품 클릭 시 상품 상세 페이지로 이동 ✅
> - 상품을 장바구니에 담는 대신 바로 구매 버튼 클릭 시 장바구니에 담고 결제 페이지로 이동 ✅
